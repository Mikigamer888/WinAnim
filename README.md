# This is the official WinAnim's repo

Code made mostly by [Gemini](https://gemini.google.com).

## About
WinAnim is a Windows boot simulator. It is built with C# and includes the .NET 5.0 runtime to ensure compatibility across various Windows environments.

## Source code not working
Make sure you ripped the **segoe_slboot.ttf** font from **C:\Windows\Boot\Fonts**.
The font needs to be an embedded resource.

## Sharing the modified source code
To make sure you aren't getting in legal trouble do not share **segoe_slboot.ttf**.
